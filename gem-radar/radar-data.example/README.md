Example local-fallback records. Every value here is TEST/MOCK (invented) and every
record's `source` says so, so Gem Radar labels any verdict that uses them.

To use local data for real, copy your own exports into `./radar-data/` (in the folder
you run Claude Code from) or point `GEM_RADAR_DATA_DIR` at a folder. This example
folder is deliberately NOT named `radar-data`, so it is never read by accident.
